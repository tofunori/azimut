Camera positions that are precise, checked and documented.

Azimut turns a DJI flight folder and a base station into positions ready for PIX4D, Metashape and OpenDroneMap: PPK, uncertainties, reference frame, CGVD2013 heights and a quality report you can read at a glance.

How it works

From the SD card to your photogrammetry software

Azimut checks first, computes next, and always says what it did: every position carries its status, its uncertainty and its reference frame.

Install

One line, and you are ready

Paste the command into a terminal. The RTKLIB-EX GNSS engine is included; nothing else to install.

Windows

Open PowerShell and paste:

irm https://raw.githubusercontent.com/tofunori/azimut/main/scripts/install.ps1 | iex

macOS · Linux

Open the Terminal and paste:

curl -fsSL https://raw.githubusercontent.com/tofunori/azimut/main/scripts/install.sh | sh
Or download the archive: Windows macOS Apple silicon macOS Intel Linux All releases →

Use

Three commands per flight

You need the copy of the drone's SD card, the base station's RINEX and, ideally, the CSRS-PPP report for that base. Step by step: the installation guide and PPK guide.

Check

Missing bands, MRK pairing, base coverage. Nothing is changed.

azimut scan flights/ --base base.24o

Compute

PPK against the base, CGVD2013 heights, quality report.

azimut process flights/ --base base.24o \
  --base-ppp base.sum --geoid ca_nrc_CGG2013an83.tif \
  --out results

Use

Import into PIX4Dmatic, Metashape or ODM, or write into copies of the images.

azimut write-images \
  results/flight_solution.json --mode copy

The quality report

Understand a flight in ten seconds

Every flight gets an HTML report, in English or French, and its JSON version for scripts.

  • A banner that says whether all is well, or what to check
  • The camera map, coloured by solution status
  • The uncertainty of every capture along the flight
  • The base: distance, coverage, reference frame

Features

Everything between the drone and the orthomosaic

Azimut replaces the geotagging step; photogrammetry stays in the software you already use.

🔎

Diagnose first

Whole SD cards in seconds, from image headers only.

🛰️

PPK

RTKLIB-EX against your base; each file positioned at its own exposure time.

🌈

Mavic 3M

Five files per capture; the bands, exposed 26 ms after the RGB image, get their own position.

📍

CSRS-PPP & RTK

Base positioned by NRCan CSRS-PPP; RTK flights corrected by the base shift.

📏

CGVD2013 heights

Or ellipsoidal, with a check that the geoid matches the frame.

📤

Outputs

PIX4Dmatic, Metashape, OpenDroneMap, CSV, HTML and JSON report.

🖼️

Into the images

EXIF and DJI XMP, in place (undoable) or into copies, radiometry untouched.

🤖

Agents

Claude or Codex run the workflow and ask you at each decision.
